Credit Scoring Machine Learning Project

Project Overview

This project predicts the credit risk of loan applicants using Machine Learning classification algorithms.

Algorithms Used

- Logistic Regression
- Decision Tree
- Random Forest

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Model Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

Project File

"Credit_Scoring_ML_Project.ipynb"

Objective

To build and compare machine learning models for predicting credit risk and supporting better lending decisions.
